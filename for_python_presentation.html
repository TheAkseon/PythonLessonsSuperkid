Цикл for в Python

Обычная понятная презентация с большим количеством практики, задач, мини-проектов и викториной именно по циклу for.

Цель

Научиться использовать for, когда нужно пройтись по числам, строкам, спискам и данным.

Формат

Короткая теория, сразу практика, затем задачи на выбор и финальный мини-проект.

Итог

Ученики понимают, когда использовать for, и умеют решать задачи без копипасты.

Зачем нужен for

Цикл for нужен, когда мы хотим пройтись по набору значений.


  • по числам из range;
  • по буквам строки;
  • по элементам списка;
  • по индексам, если нужно работать с позициями.
Главная мысль

Если понятно, по чему мы идем, чаще всего подойдет for.

Синтаксис

for переменная in набор_значений:
    действие
Как читать

Для каждого значения из набора положи это значение в переменную и выполни блок кода.


Переменную можно называть понятно: number, letter, mark, player.

Как for работает внутри

Механика
  1. Python берет первый элемент из набора.
  2. Кладет его в переменную цикла.
  3. Выполняет тело цикла.
  4. Берет следующий элемент.
  5. Когда элементы закончились, цикл завершается.
for number in [10, 20, 30]:
    print("Сейчас number =", number)

print("Цикл закончился")

Переменная цикла

Переменная цикла каждый раз получает новое значение.


Ее имя выбираем по смыслу: number, letter, price, player.

for price in [100, 250, 90]:
    print("Цена товара:", price)

for letter in "code":
    print("Буква:", letter)

for + range

for i in range(5):
    print(i)
  • range(5) дает числа 0, 1, 2, 3, 4.
  • range(1, 6) дает 1, 2, 3, 4, 5.
  • range(2, 11, 2) дает 2, 4, 6, 8, 10.

Почему конец range не включается

Важно

range(1, 6) дает 1, 2, 3, 4, 5.


Второе число - это граница остановки. Python останавливается перед ней.

for number in range(1, 6):
    print(number)

# Вывод:
# 1
# 2
# 3
# 4
# 5

Шаг в range

for number in range(0, 11, 2):
    print(number)

for number in range(10, 0, -1):
    print(number)
Формула

range(start, stop, step)


  • start - откуда начинаем;
  • stop - где останавливаемся;
  • step - как двигаемся.

Шаблон

Перед циклом создаем переменную для результата. Внутри цикла постепенно обновляем ее.


total += number

Паттерны внутри for

Сумма

Создаем total = 0 и прибавляем значения внутри цикла.

Счетчик

Создаем count = 0 и увеличиваем, если условие выполнено.

Максимум

Храним лучший результат и обновляем его, если нашли больше.

Флаг

Создаем found = False, меняем на True, если нашли нужный элемент.

for по строке

word = "python"

for letter in word:
    print(letter)

Строка состоит из символов. Цикл for может взять каждый символ по очереди.


  • считать буквы;
  • искать символы;
  • делать проверку ника;
  • создавать текстовые эффекты.

Что можно делать с символами

text = "Python 3"

for symbol in text:
    if symbol.isalpha():
        print(symbol, "буква")
    elif symbol.isdigit():
        print(symbol, "цифра")
    else:
        print(symbol, "другой символ")
  • isalpha() проверяет буквы;
  • isdigit() проверяет цифры;
  • lower() приводит к нижнему регистру;
  • upper() приводит к верхнему регистру.

for по списку

Список - это набор элементов. Через for можно обработать каждый элемент одинаковым способом.

Элемент или индекс?

marks = [5, 4, 3]

# Когда нужен сам элемент
for mark in marks:
    print(mark)

# Когда нужен номер элемента
for i in range(len(marks)):
    print("Оценка", i + 1, "=", marks[i])
Правило

Если нужен только элемент, перебираем список напрямую. Если нужен номер или несколько списков одновременно, используем индекс.

Индексы нужны, когда нужно одновременно работать с несколькими списками или знать номер элемента.


Позже можно показать enumerate, но для первого урока достаточно range(len(...)).

break и continue в for

items = ["меч", "монета", "ключ", "зелье"]

for item in items:
    if item == "ключ":
        print("Ключ найден")
        break

for number in range(1, 11):
    if number % 2 != 0:
        continue
    print(number)
  • break останавливает цикл досрочно;
  • continue пропускает текущий круг;
  • в for они работают так же, как в других циклах.

Мини-практика: рейтинг игроков

Задача
  • есть список игроков и список очков;
  • вывести каждого игрока и его очки;
  • найти победителя;
  • посчитать средний результат;
  • вывести игроков, которые набрали больше среднего.

Разбор: рейтинг игроков

players = ["Аня", "Миша", "Лера", "Даня"]
scores = [120, 95, 180, 140]

total = 0
best_score = scores[0]
best_player = players[0]

for i in range(len(players)):
    print(players[i], "-", scores[i])
    total += scores[i]

    if scores[i] > best_score:
        best_score = scores[i]
        best_player = players[i]
average = total / len(scores)

print("Победитель:", best_player)
print("Средний результат:", average)

print("Выше среднего:")
for i in range(len(players)):
    if scores[i] > average:
        print(players[i], scores[i])

Вложенные циклы for

for row in range(3):
    for col in range(5):
        print("*", end="")
    print()

Вложенный цикл - это цикл внутри цикла. Он полезен для таблиц, сеток, пиксель-арта и повторяющихся строк.

width = 8

Частые ошибки с for

  • ждать, что range(5) даст число 5;
  • забывать двоеточие после строки for;
  • путать элемент списка и индекс;
  • изменять список внутри цикла без понимания последствий;
  • использовать while, хотя данные уже лежат в списке.

Итоги

  • for перебирает значения из диапазона, строки или списка.
  • range помогает повторить код нужное количество раз.
  • Счетчики и суммы удобно обновлять внутри цикла.
  • Вложенные for подходят для таблиц и рисунков.
  • Если данные уже есть в наборе, чаще всего выбираем for.
