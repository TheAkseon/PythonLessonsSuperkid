Практика 2 минуты

Переделай код, чтобы вывести 10, 8, 6, 4, 2.

Подсказка: старт, условие и шаг должны работать в одну сторону.

Главная идея

Пока условие истинно, повторяй блок кода.

условие действие изменение 
while условие:
    действие
    изменение_условия

Ловушка вечности

energy = 5

while energy > 0:
    print("Я еще могу!")

Что не так?

  • energy не меняется;
  • условие всегда остается True;
  • программа уходит в бесконечный режим.

Фиксим бесконечность

energy = 5

while energy > 0:
    print("Я еще могу!")
    energy -= 1
ЖИЗА Цикл стал нормальным, когда переменная наконец-то начала меняться

Практика: счетчик лайков

Задача
  • пользователь вводит число лайков;
  • программа печатает каждый лайк отдельной строкой;
  • если лайков больше 10, вывести: "Ого, пост залетел!"
likes = int(input("Сколько лайков? "))

i = 1
while i <= likes:
    print("Лайк", i)
    i += 1

while любит ввод пользователя

password = ""

while password != "python":
    password = input("Введите пароль: ")

print("Доступ открыт")
  • мы не знаем, сколько попыток понадобится;
  • цикл работает, пока пароль неверный;
  • как только условие стало ложным, цикл закончился.

Практика: вход в аккаунт

Правила
  • правильный PIN: 1234;
  • максимум 3 попытки;
  • если угадал, доступ открыт;
  • если попытки закончились, карта заблокирована.
pin = ""
attempts = 3

while pin != "1234" and attempts > 0:
    pin = input("Введите PIN: ")
    attempts -= 1

if pin == "1234":
    print("Добро пожаловать")
else:
    print("Карта заблокирована")

Флаг: переменная-переключатель

game_running = True

while game_running:
    command = input("Команда: ")

    if command == "exit":
        game_running = False
    else:
        print("Выполняю:", command)

Флаг - это тумблер.

  • True - работаем;
  • False - остановились.

Финальный челлендж: антиспам-бот

  • работает до команды стоп;
  • считает все сообщения;
  • считает сообщения спам;
  • если спама 3 раза, выводит Бан на 5 минут и завершает работу;
  • в конце выводит статистику.

Решение финального челленджа

total_messages = 0
spam_count = 0

while True:
    message = input("Сообщение: ")

    if message == "стоп":
        break

    total_messages += 1

    if message == "спам":
        spam_count += 1

    if spam_count == 3:
        print("Бан на 5 минут")
        break

print("Всего сообщений:", total_messages)
print("Спама:", spam_count)

Считаем ли команду "стоп" сообщением?

Это отличный повод поговорить о логике программы.

Что забираем с собой

  • while нужен, когда количество повторов заранее неизвестно;
  • условие остановки должно реально наступить;
  • break завершает цикл;
  • continue пропускает текущий круг;
  • счетчики и флаги делают цикл управляемым.
