## Слайд 3. Главная идея `while`

`while` читается как:

> пока условие истинно, повторяй блок кода

Схема:

```python
while условие:
    действие
    изменение_условия
```

Главное правило:

> Внутри цикла должно происходить что-то, что однажды остановит цикл.

## Слайд 4. Антипример: ловушка вечности

Что здесь не так?

```python
energy = 5

while energy > 0:
    print("Я еще могу!")
```

Ответ:

`energy` не меняется, поэтому цикл не закончится.

Исправление:

```python
energy = 5

while energy > 0:
    print("Я еще могу!")
    energy -= 1
```

Сколько раз напечатается фраза?

## Слайд 8. `break`: аварийный выход

`break` сразу завершает цикл.

```python
while True:
    text = input("Напиши что-нибудь или stop: ")

    if text == "stop":
        break

    print("Ты написал:", text)
```

Когда удобно:

- чат-боты;
- меню;
- игры;
- программы, где пользователь сам решает, когда остановиться.

## Слайд 12. Флаг: переменная-переключатель

Флаг помогает управлять циклом.

```python

    command = input("Команда: ")

    if command == "exit":
        game_running = False
    else:
        print("Выполняю:", command)
```

Флаг похож на тумблер:

- `True` - работаем;
- `False` - остановились.

## Слайд 14. Чекпоинт: найди баг

Что не так в коде?

```python
count = 1

while count <= 10:
    if count % 2 == 0:
        print(count)
```

Ответ:

Нет изменения `count`, поэтому цикл бесконечный.

Исправление:

```python
count = 1

while count <= 10:
    if count % 2 == 0:
        print(count)
    count += 1
```

## Слайд 16. Версия с random

```python
import random

secret = random.randint(1, 10)
attempts = 5

while attempts > 0:
    guess = int(input("Угадай число от 1 до 10: "))
    attempts -= 1

    if guess == secret:
        print("Победа!")
        break
    elif guess < secret:
        print("Больше")
    else:
        print("Меньше")

if guess != secret:
    print("Попытки закончились. Было число:", secret)
```

## Слайд 23. Разбор: сумма цифр числа

Идея:

Берем последнюю цифру через `% 10`, потом убираем ее через `// 10`.

```python
number = int(input("Введите число: "))
total = 0

while number > 0:
    digit = number % 10
    total += digit
    number //= 10

print("Сумма цифр:", total)
```

## Слайд 26. Решение финального челленджа

```python
total_messages = 0
spam_count = 0

while True:
    message = input("Сообщение: ")

    if message == "стоп":
        break

    total_messages += 1

    if message == "спам":
        spam_count += 1

    if spam_count == 3:
        print("Бан на 5 минут")
        break

print("Всего сообщений:", total_messages)
print("Спама:", spam_count)
```
