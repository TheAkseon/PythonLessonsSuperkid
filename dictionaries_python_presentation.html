Словари в Python

Учимся хранить данные не просто по номеру, а по понятному имени: профиль игрока, меню магазина, инвентарь, оценки и мини-база данных.

Цель

Понять пары ключ: значение и научиться уверенно читать, менять и перебирать словари.

Формат

Теория короткими блоками, быстрые вопросы, практика, разбор ошибок и финальный мини-проект.

Итог

Сможем собрать программу, где данные выглядят как настоящая анкета, карточка товара или профиль героя.

Список хранит порядок, а словарь хранит смысл

Неудобно 
hero = ["Alex", 100, 7, "sword"]

print(hero[0])
print(hero[1])

Что такое hero[1]? Здоровье? Деньги? Уровень?

Понятно 
hero = {
    "name": "Alex",
    "hp": 100,
    "level": 7,
    "weapon": "sword"
}

print(hero["name"])
print(hero["hp"])

Словарь отвечает на вопрос: что лежит по этому имени?

Идея

Словарь состоит из пар:


ключкак мы ищем значение
значениечто хранится внутри
profile = {
    "name": "Mira",
    "city": "Moscow",
    "age": 14
}

Синтаксис словаря строится вокруг двоеточия

player = {
    "nickname": "Pixel",
    "score": 1200,
    "is_online": True
}
Как читать
  • фигурные скобки создают словарь;
  • слева от двоеточия стоит ключ;
  • справа от двоеточия стоит значение;
  • пары разделяются запятыми.

Ключи должны быть уникальными, значения могут повторяться

Можно 
grades = {
    "Аня": 5,
    "Миша": 5,
    "Лера": 4
}
Опасно 
user = {
    "name": "Alex",
    "name": "Max"
}

print(user["name"])

Если ключ повторился, останется последнее значение.

Разогрев: что выведет программа?

pet = {
    "name": "Барсик",
    "type": "кот",
    "age": 3
}

print(pet["type"])
print(pet["age"])
Вопрос

Сначала ответьте без запуска кода. Потом проверьте в Python.

Правильно: мы обращаемся к значениям по ключам "type" и "age".

Значение достают по ключу в квадратных скобках

item = {
    "title": "Наушники",
    "price": 2500,
    "in_stock": True
}

print(item["title"])
print(item["price"])
Правило

Пишем имя словаря, затем ключ в квадратных скобках.


dict[key]

Если ключа нет, Python честно ругается

profile = {
    "name": "Rita",
    "age": 15
}

print(profile["city"])
Ошибка

KeyError


Это значит: “я не нашел такой ключ в словаре”.


Словарь не угадывает, что мы имели в виду.

get помогает спросить аккуратно

profile = {
    "name": "Rita",
    "age": 15
}

city = profile.get("city", "город не указан")

print(city)
Когда удобно
  • ключ может отсутствовать;
  • программа не должна падать;
  • нужно значение по умолчанию.

Словарь можно менять после создания

hero = {
    "name": "Alex",
    "hp": 100
}

hero["hp"] = 80
hero["coins"] = 25

print(hero)
Два действия
  • если ключ уже есть, значение обновится;
  • если ключа нет, появится новая пара.

Практика: собери анкету пользователя

Задача
  • создай словарь user;
  • сохрани имя, возраст и город;
  • выведи фразу “Аня из Казани, 14 лет”;
  • добавь ключ "hobby".
Подсказка

Сначала создай словарь с тремя парами, потом отдельно добавь новый ключ через квадратные скобки.


user["hobby"] = ...

Разбор: анкета пользователя

user = {
    "name": "Аня",
    "age": 14,
    "city": "Казань"
}

print(user["name"], "из", user["city"])

user["hobby"] = "рисование"
Что важно

Словарь удобно читать: сразу видно, где имя, где возраст, а где город. Новый ключ можно добавить после создания словаря.

Удаление нужно, когда данные устарели

cart = {
    "phone": 1,
    "case": 2,
    "sticker": 5
}

del cart["sticker"]

removed = cart.pop("case")

print(cart)
print(removed)
Разница
  • del просто удаляет пару;
  • pop удаляет и возвращает значение.

Перед обращением можно проверить, есть ли ключ

settings = {
    "theme": "dark",
    "volume": 70
}

if "theme" in settings:
    print("Тема:", settings["theme"])
else:
    print("Тема не выбрана")
Паттерн

Проверка через in защищает от KeyError.

Цикл по словарю по умолчанию идет по ключам

grades = {
    "Аня": 5,
    "Миша": 4,
    "Лера": 5
}

for name in grades:
    print(name)
Важно

Переменная name получает ключи: "Аня", "Миша", "Лера".

У словаря есть три главных способа перебора

keys()

Только ключи: имена, названия, логины.

values()

Только значения: оценки, цены, количество.

items()

Ключ и значение вместе.

dict

Если просто написать цикл по словарю, получим ключи.

items() удобен для красивого вывода

prices = {
    "чай": 80,
    "пицца": 450,
    "сок": 120
}

for product, price in prices.items():
    print(product, "-", price, "руб.")
Почему две переменные

items() на каждом шаге отдает пару: ключ и значение. Поэтому удобно сразу назвать их по смыслу.

Практика: меню кафе

Задача
  • создай словарь блюд и цен;
  • выведи меню строками “пицца: 450 руб.”;
  • посчитай сумму всех цен;
  • выведи среднюю цену.
Подсказка

Для красивого вывода бери блюдо и цену через items(). Для средней цены пригодятся total и len(menu).

Разбор: меню кафе

menu = {
    "пицца": 450,
    "суп": 220,
    "чай": 80
}

total = 0

for dish, price in menu.items():
    print(dish, ":", price, "руб.")
    total += price

print("Средняя цена:", total / len(menu))
Что важно

items() дает пару “блюдо и цена”, а переменная total накапливает сумму.

Пустой словарь часто наполняется по ходу программы

scores = {}

scores["Аня"] = 10
scores["Миша"] = 8
scores["Лера"] = 12

print(len(scores))
print(scores)
Когда полезно
  • собираем результаты игры;
  • считаем частоты;
  • запоминаем ответы пользователя.

Словарь отлично считает, сколько раз что-то встретилось

text = "кот пес кот хомяк пес кот"
words = text.split()

counter = {}

for word in words:
    if word in counter:
        counter[word] += 1
    else:
        counter[word] = 1

print(counter)
Идея

Ключом становится слово, а значением становится количество повторов.

Практика: счетчик букв

Задача

Пользователь вводит слово. Программа должна вывести, сколько раз встретилась каждая буква.


Например: банан превращается в счетчик букв.

Подсказка

Ключом будет буква, значением будет количество. Если буква уже есть в словаре, увеличь счетчик на 1.

Разбор: счетчик букв

word = input("Введите слово: ")
letters = {}

for letter in word:
    if letter in letters:
        letters[letter] += 1
    else:
        letters[letter] = 1

for letter, count in letters.items():
    print(letter, "-", count)
Что важно

Этот же прием работает для слов, оценок, лайков и любых повторяющихся данных.

update добавляет сразу несколько пар

player = {
    "name": "Nova",
    "level": 3
}

player.update({
    "hp": 100,
    "coins": 45,
    "guild": "Python Team"
})

print(player)
Когда удобно

Когда нужно быстро объединить данные: профиль + настройки, товар + скидка, герой + новые характеристики.

Функции хорошо дружат со словарями

def show_player(player):
    print("Игрок:", player["name"])
    print("Уровень:", player["level"])
    print("HP:", player["hp"])

hero = {
    "name": "Nova",
    "level": 4,
    "hp": 90
}

show_player(hero)
Связь с прошлой темой

Словарь можно передать в функцию как один аргумент, вместо трех-четырех отдельных переменных.

Практика: функция печатает карточку товара

Задача
  • создай словарь товара;
  • напиши функцию show_product(product);
  • выведи название, цену и наличие;
  • если товара нет, напечатай “нет в наличии”.
Подсказка

Передай словарь в функцию одним аргументом. Внутри функции доставай поля товара по ключам.

Разбор: карточка товара

def show_product(product):
    print("Товар:", product["title"])
    print("Цена:", product["price"])

    if product["in_stock"]:
        print("Есть в наличии")
    else:
        print("Нет в наличии")

phone = {
    "title": "Смартфон",
    "price": 29900,
    "in_stock": True
}

show_product(phone)
Что важно

Функция не зависит от конкретного товара. Ей можно передать другой словарь с такими же ключами.

Когда объектов много, используем список словарей

students = [
    {"name": "Аня", "grade": 5},
    {"name": "Миша", "grade": 4},
    {"name": "Лера", "grade": 5}
]

for student in students:
    print(student["name"], student["grade"])
Как думать

Список хранит много объектов. Каждый объект внутри описан словарем.

Практика: рейтинг игроков

Задача

Есть список игроков. Выведи только тех, у кого больше 100 очков.

Стартовые данные 
players = [
    {"name": "Fox", "score": 80},
    {"name": "Neo", "score": 140},
    {"name": "Kit", "score": 110}
]

Разбор: рейтинг игроков

players = [
    {"name": "Fox", "score": 80},
    {"name": "Neo", "score": 140},
    {"name": "Kit", "score": 110}
]

for player in players:
    if player["score"] > 100:
        print(player["name"], "прошел дальше")
Что важно

Каждый player внутри цикла — это отдельный словарь. Поэтому очки читаются как player["score"].

Вложенный словарь хранит данные внутри данных

game = {
    "player": {
        "name": "Nova",
        "hp": 90
    },
    "enemy": {
        "name": "Bot",
        "hp": 60
    }
}

print(game["player"]["name"])
Не спешим

Читаем слева направо: зайди в game, потом в player, потом возьми name.

Большинство ошибок в словарях связано с ключами

KeyError

Обратились к ключу, которого нет.

Опечатка

"name" и "Name" для Python разные ключи.

Скобки

Для словаря нужны {}, для обращения нужны [].

Повтор ключа

Последнее значение перезапишет предыдущее.

Викторина: что вернет get?

user = {
    "name": "Tim",
    "age": 13
}

print(user.get("city", "неизвестно"))
Выберите ответ
Правильно: ключа "city" нет, поэтому вернется значение по умолчанию.

Финальный проект: мини-магазин

Что сделать
  • создать меню товаров и цен;
  • попросить пользователя выбрать товар;
  • если товар есть, добавить цену к сумме;
  • команда stop завершает покупку;
  • в конце вывести итоговую сумму.
Усложнение
  • после каждой покупки показывай текущую сумму;
  • сохраняй купленные товары в список;
  • в конце выведи чек.

Разбор: мини-магазин

products = {
    "чай": 80,
    "печенье": 120,
    "сок": 150
}

total = 0

while True:
    choice = input("Что купить? ")

    if choice == "stop":
        break

    if choice in products:
        total += products[choice]
        print("Добавлено")
    else:
        print("Такого товара нет")

print("Итого:", total)
Что важно

Словарь хранит цены, while держит покупку открытой, а проверка choice in products защищает от неправильного товара.

Словари нужны, когда данным нужны имена

  • get помогает избежать падения;
  • items() удобно использовать в цикле;
  • список словарей описывает много похожих объектов.
