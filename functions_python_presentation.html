Функции в Python

Учимся писать код, который не повторяется: параметры, return, значения по умолчанию и возврат нескольких значений.

Цель

Научиться выносить повторяющийся код в функции и вызывать их с разными данными.

Формат

Короткая теория, сразу практика, паттерны, мини-проект и финальный баттл.

Итог

Умеем писать функции с параметрами, возвращать результат и использовать значения по умолчанию.

Зачем нужны функции

Проблема 
print("Привет, Аня!")
print("Как дела, Аня?")

print("Привет, Миша!")
print("Как дела, Миша?")

print("Привет, Лера!")
print("Как дела, Лера?")
Решение 
def greet(name):
    print("Привет,", name)
    print("Как дела,", name)

greet("Аня")
greet("Миша")
greet("Лера")

Синтаксис def

def имя_функции(параметры):
    тело функции
Как читать
  • def — объявляем функцию;
  • имя пишем маленькими буквами через _;
  • в скобках — параметры (или пусто);
  • двоеточие и отступ — как в if и for.

Функция не выполняется при объявлении. Она запускается только при вызове.

Как работает вызов

Механика
  1. Python доходит до строки с вызовом.
  2. Переходит внутрь функции.
  3. Выполняет тело функции.
  4. Возвращается к следующей строке после вызова.
def say_hello():
    print("Привет!")
    print("Я функция")

print("До вызова")
say_hello()
print("После вызова")

Главная мысль

Функция написана один раз, но вызывается сколько угодно раз.


Если нужно поменять приветствие — меняем только внутри def, а не в каждом месте кода.

Параметры функции

def greet(name):
    print("Привет,", name)

greet("Аня")
greet("Миша")
greet("Лера")
Как работает

Параметр — это переменная внутри функции. При вызове мы передаём значение, и оно попадает в эту переменную.


  • name — параметр (в определении);
  • "Аня" — аргумент (при вызове).

Несколько параметров

def introduce(name, age):
    print("Меня зовут", name)
    print("Мне", age, "лет")

introduce("Аня", 16)
introduce("Миша", 14)

def show_score(player, score, max_score):
    print(player, "набрал", score, "из", max_score)
Важно

Аргументы передаются по порядку. Первый аргумент — первому параметру, второй — второму.


Если перепутать порядок, получим неожиданный результат.

return — возврат значения

def add(a, b):
    return a + b

result = add(3, 5)
print(result)       # 8

print(add(10, 20))  # 30
Как работает

return отправляет значение обратно туда, откуда вызвали функцию.


  • результат можно сохранить в переменную;
  • можно передать сразу в print;
  • можно использовать в выражении.

После return функция завершается.

print против return

print внутри 
def add_print(a, b):
    print(a + b)

x = add_print(3, 5)
# Выведет: 8
# x = None !

Выводит на экран, но ничего не возвращает. Результат нельзя использовать дальше.

return 
def add_return(a, b):
    return a + b

x = add_return(3, 5)
# x = 8
print(x * 2)  # 16

Возвращает значение. Его можно сохранить, передать дальше, использовать в вычислениях.

Разбор практики 3

def square(n):
    return n * n

def is_even(n):
    return n % 2 == 0

def get_max(a, b):
    if a > b:
        return a
    return b

print(square(5))      # 25
print(is_even(4))     # True
print(get_max(7, 3))  # 7
def average(a, b, c):
    return (a + b + c) / 3

result = average(80, 90, 100)
print("Среднее:", result)  # 90.0

# Используем в условии
if average(5, 4, 3) >= 4:
    print("Хороший результат")

Значения по умолчанию

def greet(name, greeting="Привет"):
    print(greeting + ",", name + "!")

Как работает

Если при вызове не передать аргумент — используется значение по умолчанию.


  • параметры с дефолтом — всегда в конце;
  • дефолт можно переопределить при вызове;
  • удобно, когда один вариант используется чаще всего.

Возврат нескольких значений

def min_max(numbers):
    minimum = numbers[0]
    maximum = numbers[0]

    for n in numbers:
        if n < minimum:
            minimum = n
        if n > maximum:
            maximum = n

    return minimum, maximum

scores = [45, 90, 78, 100, 55]
low, high = min_max(scores)
print("Мин:", low, "Макс:", high)
Как работает

Перечисляем значения через запятую после return. При получении тоже через запятую.


Python упаковывает их в кортеж и распаковывает при присваивании.

Паттерны с функциями

Обёртка цикла

Выносим цикл в функцию: def find_max(items), def calc_sum(items). Вызываем для разных списков.

Валидатор

Функция проверяет данные и возвращает True/False: def is_valid_nick(nick).

Форматтер

Функция возвращает готовую строку: def format_score(name, score) → "Аня: 120 очков".

Мини-калькулятор

Набор функций add, subtract, multiply — каждая делает одно действие и возвращает результат.

Мини-проект: аналитика стрима

Задача
  • дан список донатов;
  • написать функцию calc_total(donates) — сумма;
  • написать функцию find_max(donates) — максимум;
  • написать функцию count_big(donates, limit) — сколько донатов больше лимита;
  • написать функцию stream_report(donates) — вызывает все три и выводит итог.
donates = [100, 750, 300, 1200, 50, 900]

def calc_total(donates):
    total = 0
    for d in donates:
        total += d
    return total

def find_max(donates):
    max_d = donates[0]
    for d in donates:
        if d > max_d:
            max_d = d
    return max_d

Разбор: аналитика стрима

def count_big(donates, limit=500):
    count = 0
    for d in donates:
        if d > limit:
            count += 1
    return count

def stream_report(donates):
    print("Сумма донатов:", calc_total(donates))
    print("Максимальный:", find_max(donates))
    print("Больше 500:", count_big(donates))
    if calc_total(donates) > 3000:
        print("Стрим залетел!")
donates = [100, 750, 300, 1200, 50, 900]
stream_report(donates)

# Сумма донатов: 3300
# Максимальный: 1200
# Больше 500: 3
# Стрим залетел!

Частые ошибки

  • забыть вызвать функцию — написали def, но не написали вызов;
  • использовать print вместо return и потом удивляться, почему переменная None;
  • перепутать порядок аргументов при вызове;
  • поставить параметр с дефолтом перед обычным параметром;
  • обращаться к переменной внутри функции снаружи;
  • забыть return — функция вернёт None по умолчанию.

Баттл задач по функциям

Раунд 1

Функция celsius_to_fahrenheit(c): перевести градусы. Формула: f = c * 9/5 + 32.

Раунд 2

Функция is_palindrome(word): возвращает True, если слово читается одинаково в обе стороны.

Раунд 3

Функция count_vowels(text): считает гласные буквы в тексте.

Раунд 4

Функция get_stats(numbers): возвращает сумму, минимум и максимум списка.

Разбор баттла

def celsius_to_fahrenheit(c):
    return c * 9 / 5 + 32

def is_palindrome(word):
    return word == word[::-1]

def count_vowels(text):
    vowels = "аеёиоуыэюяАЕЁИОУЫЭЮЯ"
    count = 0
    for letter in text:
        if letter in vowels:
            count += 1
    return count
def get_stats(numbers):
    total = 0
    minimum = numbers[0]
    maximum = numbers[0]
    for n in numbers:
        total += n
        if n < minimum:
            minimum = n
        if n > maximum:
            maximum = n
    return total, minimum, maximum

s, lo, hi = get_stats([5, 2, 8, 1, 9])
print(s, lo, hi)  # 25 1 9

Правильно: name обязателен, greeting имеет дефолт. greet("Аня") работает.

Викторина: вопрос 4

Что вернёт функция?

    if n > 0:
        return "плюс"
    elif n < 0:
        return "минус"
    return "ноль"

print(check(0))
Правильно: 0 не больше 0 и не меньше 0, поэтому доходим до return "ноль".

Итоги

  • def объявляет функцию, вызов — отдельная строка с именем и скобками.
  • Параметры — переменные внутри функции, аргументы — значения при вызове.
  • return возвращает результат; без него функция возвращает None.
  • Значения по умолчанию делают параметры необязательными.
  • Можно вернуть несколько значений через запятую.
